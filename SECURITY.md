# Безопасность

Об уязвимости сообщай не в открытом issue, а через [Security → Report a vulnerability](https://github.com/Redox-openDriver/papilla/security/advisories/new)
на GitHub: сообщение увидят только сопровождающие. Опиши, что нужно сделать, чтобы воспроизвести, и что из этого
следует.

Модель угроз драйвера, который пользуется этой библиотекой, — в
[elanfp-0c4b/SECURITY.md](https://github.com/Redox-openDriver/elanfp-0c4b/blob/main/SECURITY.md).
